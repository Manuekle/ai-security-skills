# Security Policy

These skills provide security-review guidance; they are not a substitute for professional security testing, provider documentation, or environment-specific threat modeling.

## Reporting a problem

If you find instructions in this repository that could cause an agent to weaken a security boundary, expose credentials, bypass authorization, or execute unsafe actions, please report it privately to the repository maintainer before opening a public exploit demonstration.

When reporting, include:

- affected skill and file
- problematic instruction
- realistic impact
- proposed safer wording, if available

Do not include real secrets or sensitive customer data in reports.
